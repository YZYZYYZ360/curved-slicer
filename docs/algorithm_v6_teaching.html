导论：为什么要把可制造性翻译成"边权"

本节学完后你应该能回答：为什么我们放弃了偏微分方程路线，转向"在体素图上做最短路径"。

问题回顾

我们的输入是一个三维模型（如毛主席头雕），目标是切成一层一层的弯曲薄壳，让六轴机器人不需要任何支撑就能打印出来。

任何曲面层切片算法必须同时满足四件事：

编号名称含义
C1邻接粘合每个新体素必须有"贴得住的邻居"在前层（粘得住的物理条件）
C2机器人能摸到逆运动学有解 + 关节不越限 + 远离奇异点
C3喷头本体不撞喷头圆柱体不能撞到已打印部分
C4曲面不太弯表面最大主曲率不能超过喷头半径倒数（喷头塞得进凹陷）

失败的两条老路

为什么不用偏微分方程？
我们之前 v4 走的是"解 ∇²φ = ∇·G + 切等值面"的偏微分方程路线。这条路对兔子这种简单凸几何能跑，但对毛主席头雕必然崩，根本原因：脸的法向指 +X、后脑勺指 −X、头顶指 +Z，这个法向场有"漩涡"（数学上叫 curl ≠ 0），偏微分方程根本无法用单一标量场 φ 表达这种漩涡。
为什么不用 Wang 2018 的贪婪推进？
Wang 2018 的"贪婪邻接推进"是构造式的：从平台开始一格一格往外加体素，只要新体素有邻居在前层就接受。这条路保证了 C1，但完全不考虑 C2/C3/C4。论文自己也承认对 Armadillo 尾根有 10752 个体素永远到不了（叫"阴影区"失败）。

v6.2 的新思路：把四个约束统统翻译成"边权"

关键转变：

不要求场上每一点都严格满足 C1-C4，但让"难加工"的位置在算法层面"代价更高"，于是最短路径会自然绕开它们。

图示：最短路径在"易加工"区域穿过，自然避开"难加工"区域（橙色虚线 = 加权距离场的最短路径）

这个思路有什么深刻之处？
我们把"是否可加工"的问题，从布尔判定（能/不能）转成连续标量（多容易/多难）。布尔判定对边界敏感，连续标量更鲁棒。算法上对应的工具就是带权最短路径（Dijkstra 算法），它天然适合处理"每条边有代价、总代价最小"的问题。
必须诚实承认的局限
"高代价 ≠ 禁止"。如果一个体素被四面包围全是高代价区，最短路径仍会从中间穿过（没有替代路径）。所以 C1-C4 的真正满足靠事后验证（第六阶段做），不是算法保证。这点必须写进论文："标量场提供软引导，约束满足由事后验证判定。"

第一节：四个基础场

本节学完后你应该能：(1) 说出每个场代表什么物理量；(2) 知道每个场怎么算出来；(3) 理解为什么需要每个场。

1.1 符号距离场（SDF）

这个场代表什么

每个体素中心到模型表面的最近距离，带正负号。

  • 正值：体素在模型外面（如背景空气）
  • 负值：体素在模型内部（如模型实体）
  • 零值：体素正好落在表面上

怎么算

  1. 对输入网格调 igl::signed_distance（底层用包围盒树 + 绕数判断内外）
  2. 只在窄带模式下算：|符号距离| ≤ 3 倍体素尺寸的体素算精确值，其余标无穷
  3. 单位：毫米（mm）
为什么是窄带模式
我们后面所有计算都只关心表面附近的体素（喷头会经过的地方），远离表面的体素不需要精确距离。窄带模式让 SDF 计算从 O(N²) 降到 O(N log N)，对毛主席模型（约 27 万体素）从分钟级降到秒级。

为什么需要这个场

SDF 是所有其他场的基础：

  • 局部开口半径场：用 SDF 做射线投射的起点
  • 最大主曲率场：从 SDF 间接推导
  • 平滑法向场：从 SDF 梯度的方向推导
  • 凹陷风险惩罚：间接通过开口半径场依赖 SDF
数值坑：中轴上的不连续
在模型的"中轴"（离两个表面等距的点集）上，SDF 理论上不可微（出现尖点）。离散网格上会表现为奇异值。计算梯度 ∇SDF 时，对 |∇SDF| < ε 的位置要跳过。

1.2 局部开口半径场

这个场代表什么

每个表面附近体素的"喷头能从外面塞进来的最大半径"。直接服务于后面的凹陷风险惩罚。

关键认知：开口半径 ≠ 符号距离
"到表面的距离"和"喷头能塞进来的半径"是两个不同的几何量。
  • SDF 问的是"我离表面多远"
  • 开口半径问的是"我周围有多大空间能容纳一个球"
对于凹陷深处的点，可能离表面很近（SDF 小），但开口很窄（开口半径也小，喷头塞不进）。这两个不能混用。

怎么算

  1. 选起点：对每个表面附近体素 v，从 v 沿外法向偏移 0.5mm（保证起点在模型外）作为射线起点 p。
  2. 32 方向射线投射：从 p 沿 32 个均匀分布的方向 d₁, d₂, ..., d₃₂ 射出射线，找每条射线第一次撞到"反面"（模型另一侧的表面）的距离 l₁, l₂, ..., l₃₂。
  3. 取第 20 百分位作为半径估计：
    开口半径(v) = 排序后(l₁, ..., l₃₂) 的第 20 百分位 ÷ 2

从体素中心射出 32 条射线（图中示意 8 条），找每条射线碰到模型对面的距离

为什么是第 20 百分位，不是最小值？
  • 用最小值太悲观：只要一个方向上有一个长突起伸过来，整个邻域就被标低。但工程上喷头从大多数方向能进来就够了，不需要所有方向都开放。
  • 用平均值太乐观：少数特别宽的方向会拉高平均值，掩盖真正的窄方向。
  • 第 20 百分位表示"至少有 80% 的方向开口比这个宽"，是工程上的"保守但不悲观"折中。
为什么是 32 个方向？
  • 6 个方向（仅面方向）：漏检对角线开口，太粗糙
  • 100 个方向：精度增加可忽略，计算时间多 3 倍
  • 32 个方向：球面 Fibonacci 均匀采样的工程甜点

为什么需要这个场

直接服务于凹陷风险惩罚 p_clear（第二节 2.1）。喷头是有体积的圆柱，进不去窄缝；这个场告诉算法"哪里窄"。

1.3 最大主曲率场

这个场代表什么

每个表面附近体素处，曲面在该点弯曲程度的上界。直接服务于约束 C4（喷头球塞不进半径小于 r_n 的凹陷）。

什么是主曲率

在曲面上任意一点，沿不同方向的"弯曲程度"不同。最大的弯曲程度叫 κ₁（第一主曲率），最小的叫 κ₂（第二主曲率）。

几何形状κ₁ 和 κ₂解释
球面（半径 R）κ₁ = κ₂ = 1/R各方向弯曲一样
圆柱面（半径 R）κ₁ = 1/R, κ₂ = 0一个方向弯，另一个方向直
鞍面（如马鞍）κ₁ = +1/R, κ₂ = −1/R一个方向凸，另一个方向凹
平面κ₁ = κ₂ = 0不弯
关键修正：用最大主曲率，不用平均曲率
平均曲率定义为 H = (κ₁ + κ₂) / 2。对于鞍面 κ₁ = −κ₂，平均曲率 H = 0，但单方向上喷头仍可能塞不进去（κ₁ 或 κ₂ 绝对值大）。

所以我们用 max(|κ₁|, |κ₂|) 而不是 |H|。

怎么算

  1. 在网格顶点上算：调 igl::principal_curvature，它内部用"形状算子"（shape operator）从网格的二阶基本形式中提取 κ₁, κ₂。
  2. 插值到体素：对每个表面附近体素 v，找最近的网格顶点 v_nearest，把它的曲率赋给 v：
    κ_max(v) = max(|κ₁(v_nearest)|, |κ₂(v_nearest)|)
为什么不直接用 SDF 的 Hessian 估曲率？
理论上有公式 H = ∇·(∇SDF / |∇SDF|)，看起来很方便。实际上行不通：
  • 0.5mm 体素上算 SDF，本身误差约 ±0.05mm（约 10%）
  • 一阶导（梯度）放大误差到 ±0.1（噪声/信号比 ≈ 20%）
  • 二阶导（Hessian）继续放大到 ±0.5（噪声/信号比 ≈ 100%）
  • 对于 1/r_n = 0.1 mm⁻¹ 这种细微判据，信噪比根本不够
而形状算子直接在网格表面上算（不依赖体素 SDF），精度高得多。

1.4 平滑法向场

这个场代表什么

每个体素处的"曲面外法向方向"，单位向量。

怎么算

  1. 从网格顶点法向（igl::per_vertex_normals）插值到体素
  2. 做 1-2 轮邻域平均（去除高频噪声）
  3. 单位化
为什么需要平滑？
原始顶点法向在网格边界、尖角处不连续（同一顶点不同三角面给出不同法向）。如果直接用，下游用到法向的地方（如朝向惩罚 p_orient）会跳变。

1-2 轮邻域平均够了。更多次平均会让局部细节丢失（比如本来该指向不同方向的两个尖角被抹平成一个方向）。

为什么需要这个场

  • 第二节 2.2：朝向惩罚 p_orient 需要 N_smooth 算"融合式偏好方向" B(v)
  • 第六节：工具姿态估计用 ∇SDF 的方向（与 N_smooth 几乎一致，但 ∇SDF 在中轴附近不稳，N_smooth 更平滑）

场物理意义用途
符号距离场到表面的距离所有其他场的基础

2.1 凹陷风险惩罚 p_clear

物理动机

如果某体素附近的开口比喷头本体还窄，喷头根本进不去 → 算法应该让最短路径避开这个区域。

定义推导

朴素想法：开口小于喷头半径就罚。

p_clear_朴素(v) = max(0, r_n − 开口半径(v))

这个公式有两个问题：

  1. 缺少安全余量：体素离散化误差约 ±0.5mm，喷头校准误差约 ±1mm，应该留出"余量"
  2. 线性惩罚不够区分：差 0.1mm 和差 5mm 应该有数量级差异，不该都是线性

改进 1：加余量 margin = 2mm。

p_clear(v) = max(0, r_n + margin − 开口半径(v))

改进 2：平方，让"差很多"惩罚远大于"差一点"。

p_clear_raw(v) = max(0, r_n + margin − 开口半径(v))²
最终定义
假设 r_n = 10mm, margin = 2mm。考虑三个体素：
  • 体素 A：开口半径 = 15mm（开口很宽）→ p_clear = max(0, 12 − 15)² = 0 → 不罚
  • 体素 B：开口半径 = 11mm（刚好够）→ p_clear = max(0, 12 − 11)² = 1 → 微罚
  • 体素 C：开口半径 = 8mm（不够）→ p_clear = max(0, 12 − 8)² = 16 → 重罚
  • 体素 D：开口半径 = 2mm（极窄）→ p_clear = max(0, 12 − 2)² = 100 → 极重罚
为什么不直接做硬掩码（开口半径小于 r_n 就拒绝该体素）？
硬掩码会让 Dijkstra 在边界处突变 → 等值面提取后碎裂。软惩罚让算法平滑过渡，最短路径会"绕远"但不"断"。

这是算法稳定性的关键设计选择：软惩罚 + 事后验证，不是硬约束。

单位

mm²（量纲会在归一化阶段抹平）

2.2 朝向偏离惩罚 p_orient（融合式偏好方向）

物理动机

我们希望距离场"从底部往上长"，等值面随高度递增。这样切出来的弯曲层一层一层往外堆，符合打印过程的物理逻辑。

朴素定义及其问题

p_orient_朴素(u, v) = 1 − |归一化(v − u) · 全局向上方向|

这里 (u, v) 是体素图上的一条边，"全局向上方向" = (0, 0, 1)。

  • 边方向接近 +z（往上走）→ 点积接近 1 → 罚 = 0
  • 边方向接近 ±水平（横着走）→ 点积接近 0 → 罚 = 1
  • 边方向接近 −z（往下走）→ 点积接近 −1，取绝对值后 = 1 → 罚 = 0（允许下行，但实际很少）
隐性数学问题：β 越大越像水平切片
如果只用全局向上方向，算法会逼迫所有等值面变成水平平面（这样所有边都朝上）。

但我们要的是弯曲层，应该贴合模型形状。

举例：在毛主席头顶（球冠形），最优等值面是球面（贴合头形），而不是水平切片。如果用朴素公式 + 大 β，等值面会被强行拉平，导致切出的层不贴合曲面，碎裂率上升。

修正：融合式偏好方向

我们改用一个融合的偏好方向 B(v)，每个体素自己一个：

B(v) = 归一化( (1 − η) × 全局向上方向 + η × 平滑法向(v) )

其中 η ∈ [0, 1] 是融合权重。然后：

p_orient_raw(u, v) = 1 − |归一化(v − u) · B(v)|
最终定义

融合权重 η 的物理意义

η行为
η = 0完全用全局向上方向 → 退化为朴素版 → 等值面被拉平
η = 1完全用局部法向 → 没有全局推进方向 → 可能不收敛
η = 0.3（默认）"从底部推进"的全局倾向 + "贴合形状"的局部折中

η = 0.3 时的融合偏好方向 B(v)：从底部主要朝上，到头顶逐渐贴合曲面外法向

假设全局向上方向 = (0, 0, 1)，η = 0.3。
  • 底部体素，平滑法向 ≈ (0, 0, −1)（朝下，因为外法向指向平台外侧）：
    B = 归一化( 0.7 × (0,0,1) + 0.3 × (0,0,−1) ) = 归一化( (0,0,0.4) ) = (0,0,1) → 几乎全局向上
  • 侧面体素，平滑法向 = (1,0,0)（朝侧外）：
    B = 归一化( 0.7 × (0,0,1) + 0.3 × (1,0,0) ) = 归一化( (0.3, 0, 0.7) ) ≈ (0.39, 0, 0.92) → 斜向上
  • 头顶体素，平滑法向 = (0, 0, 1)（朝上）：
    B = 归一化( 0.7 × (0,0,1) + 0.3 × (0,0,1) ) = (0,0,1) → 完全向上

单位

无量纲（点积本身在 [−1, 1]，整个 p_orient 在 [0, 1]）

2.3 曲率违反惩罚 p_curv

物理动机

曲面上某点的最大主曲率超过 1/r_n 时，喷头球塞不进该凹陷。算法应该避开这些位置。

定义

p_curv_raw(v) = max(0, κ_max(v) − 1/r_n)²

结构和 p_clear 一样：超出阈值才罚，平方让"超得多"罚重。

假设 r_n = 10mm，则 1/r_n = 0.1 mm⁻¹。
  • 体素 A：κ_max = 0.05 mm⁻¹（弯曲程度小）→ p_curv = 0 → 不罚
  • 体素 B：κ_max = 0.15 mm⁻¹（弯曲超阈值 50%）→ p_curv = max(0, 0.15−0.1)² = 0.0025
  • 体素 C：κ_max = 0.3 mm⁻¹（极弯，如尖锐凹陷）→ p_curv = max(0, 0.3−0.1)² = 0.04
这里数值看起来都很小，是因为单位是 (1/mm)² = 1/mm²。但归一化后会被映射到 [0, 1]，量纲问题消失。

何时触发

  • 毛主席头发褶皱（< 1mm 的凹陷）
  • Armadillo 关节凹陷
  • 兔子耳朵根部尖角

在第零阶段（几何调理）做完重度平滑后，大部分高曲率特征应当已被抹平。p_curv 是"剩余高曲率"的兜底。

单位

(1/mm)² = 1/mm²

2.4 逆运动学边际惩罚 p_ik（核心创新）

本小节是 v6.2 算法窄但能立的算法创新。其他三个惩罚项在文献中都有先例，但"把 KR4 R600 的逆运动学边际度注入距离场构造阶段" + "邻域分支一致性" 这两件事的组合是新的。

物理动机

距离场上某点的特性可能"几何上合理"，但机器人摆不到那里：

  • 关节角超出限位
  • 逆运动学无解（工作空间外）
  • 临近奇异点（机器人姿态不可控）

这些位置 → 算法应该让最短路径绕开 → 切出的弯曲层就在"机器人舒服"的区域。

计算流程（6 步）

对每个体素 v，我们要算一个综合的"逆运动学边际度"。流程如下：

  1. 从工具姿态估计取 tool_z（第六节会详细讲）：
    tool_z(v) = −∇SDF(v) / |∇SDF(v)| （喷头朝模型内部）
    然后构造稳定的参考轴 tool_x_ref 和 tool_y_ref（不依赖路径切线，因为路径还不存在）。
  2. 枚举 12 个偏航角采样（喷头绕 tool_z 自旋的自由度）：
    ψ ∈ {0°, 30°, 60°, ..., 330°}
    每个 ψ 给出一个完整的工具姿态矩阵 R_ψ。
  3. 解析逆运动学一次返回 8 个解分支：
    解集合 = 解析IK(v 的位置, R_ψ) 返回最多 8 个 q
    KR4 R600 是球腕机器人，对每个目标位姿最多有 8 个不同的关节角组合（前后臂×肘上下×腕翻不翻）。
  4. 对每个解算"边际度"。先做快筛去掉明显不行的（关节限位、奇异性的便宜判据），剩下的前 3 个解算精确雅可比奇异值：
    J_ik(q) = (1/3) × 关节限位惩罚(q) + (1/3) × 奇异性惩罚(q) + (1/3) × 工作空间惩罚(q)
    三个子惩罚的详细定义见下方。
  5. 取所有 (ψ, q) 组合的最小 J_ik：
    J_ik_min(v) = min J_ik(q) ψ, q
    意思是"该体素最优情况下机器人有多舒服"。
  6. 加上"邻域分支一致性"惩罚（关键创新）：
    p_ik_raw(v) = J_ik_min(v) + λ_consist × 分支波动度(v)
    其中 λ_consist = 0.5 是默认权重。下面解释为什么需要这一项。

三个子惩罚的定义

关节限位惩罚 jl_penalty

关节角离限位中央越远越不好。

jl_penalty_norm(q) = (1/6) × Σᵢ ( (qᵢ − q_中位ᵢ) / (q_范围ᵢ / 2) )²
  • q_中位ᵢ = (q_lim_minᵢ + q_lim_maxᵢ) / 2
  • q_范围ᵢ = q_lim_maxᵢ − q_lim_minᵢ
  • 关节在限位中央 → 该项 = 0
  • 关节贴在限位边缘 → 该项 ≈ 1
  • 6 关节平均权重，结果归一化到 [0, 1]

奇异性惩罚 sing_penalty

雅可比矩阵的最小奇异值 σ_min 接近 0 → 机器人某些运动方向不可控。

sing_penalty_norm(σ_min) = exp(−σ_min / σ_ref)
  • σ_ref = 0.05（经验阈值）
  • σ_min ≫ 0.05 → exp(−大数) ≈ 0 → 不罚
  • σ_min = 0.05 → exp(−1) ≈ 0.37 → 中等罚
  • σ_min → 0 → exp(0) = 1 → 罚最大
为什么用指数而不是 1/(σ + ε)？
1/(σ + ε) 在 σ → 0 时爆炸到无穷大，难归一化，下游容易出 NaN。
指数函数天然在 [0, 1] 范围内，光滑稳定。

工作空间边际惩罚 ws_penalty

工具中心点离 KR4 R600 工作空间球壳边界（内半径 100mm，外半径 600mm）越近越不好。

TCP_距离 = |正运动学(q).position − 机器人基座|
ws_penalty_norm(q) = 斜坡(TCP_距离, r_min, r_max)

斜坡函数定义：

  • 中心区（约 300-500mm）→ 0
  • 接近边界（前后 100mm 内）→ 0 到 1 线性增长
  • 已越界 → 1

分支波动度（创新点）

这是 v6.2 算法的窄创新点之一。它解决一个微妙的问题：单点逆运动学可达 ≠ 路径连续逆运动学可达。

问题描述：如果体素 v 的最优逆运动学解用了 IK 分支 3（如"前臂 + 肘上 + 腕不翻"），而它的邻居体素都用 IK 分支 5（如"后臂 + 肘下 + 腕翻"），那么沿着层走时，从 v 到邻居必须翻臂，关节角差极大，第五阶段的动态规划必然失败。

解决方法：在 p_ik 中加入"分支波动度"项，对邻域内分支频繁切换的位置加额外惩罚。

分支波动度(v) = 1 − ( 主导分支在邻域中的占比 )

具体算法：

  • 找出体素 v 的 26 个邻居（3×3×3 立方除自己）
  • 每个邻居都有一个最优 IK 分支编号
  • 找出现次数最多的分支（"主导分支"），数它在 26 个邻居中占的比例
  • 波动度 = 1 − 该比例
  • 26 个邻居全选 IK 分支 3 → 主导比例 = 26/26 = 1 → 波动度 = 0
  • 13 个邻居选分支 3，13 个选分支 5 → 主导比例 = 13/26 = 0.5 → 波动度 = 0.5
  • 完全分散到 8 个不同分支 → 主导比例 ≈ 0.1 → 波动度 ≈ 0.9
为什么这个项关键？
没有它的话，distance field 只会避开"单点不可达"的位置，但仍会穿过"单点可达但路径不连续"的位置。结果是 distance field 看起来漂亮，但下游路径生成阶段大批失败。

有了它，distance field 不仅避开"摆不到"的位置，还避开"摆得到但摆不连贯"的位置。

p_ik 的两个工程优化

优化 1：粗网格。如果对每个 0.8mm 体素都算 p_ik，毛主席模型约 27 万体素，每体素 96 个候选（12 偏航 × 8 分支），单次精确计算约 16 微秒，总耗时约 7 分钟。

改进：用 1.6mm 粗网格算 p_ik（约 3.4 万体素），然后三线性插值回 0.8mm。耗时约 50 秒，分辨率损失对 bias 用途可忽略。

优化 2：多线程。p_ik 计算是"非常容易并行"的（每个体素独立），用 OpenMP 8 线程进一步提速 5-7 倍。

第二节小结

惩罚项对应约束公式结构
p_clear（凹陷风险）C3 喷头不撞max(0, r_n + margin − 开口半径)²
p_orient（朝向偏离）C1 间接（推进性）1 − |边方向 · 融合偏好方向|
p_curv（曲率违反）C4 曲率干涉max(0, κ_max − 1/r_n)²

第三节：惩罚项归一化

本节学完后你应该能：解释为什么必须做归一化、归一化算法的每一步在干什么。

为什么必须归一化

第二节算出来的 4 个惩罚项量纲完全不同：

惩罚项单位典型量级
p_clearmm²0 到 150（差距 8mm 时罚 64）
p_orient无量纲0 到 1
p_curv1/mm²0 到 0.01（极小）
p_ik综合（无量纲）0 到 100（极不稳定，取决于奇异性附近）

如果不归一化直接 α·p_clear + β·p_orient + γ·p_curv + δ·p_ik，会出现：

不归一化的后果
  • δ 的物理意义不可解释。δ = 0.5 可能压倒其他全部，也可能完全无影响——取决于 p_ik 实际范围
  • γ·p_curv 数值太小，γ 怎么调都没效果
  • 论文里写"α = 1, β = 0.3, γ = 0.1, δ = 0.5"——审稿人会问"为什么这些数？怎么调出来的？"答不出
  • 消融实验不可解释

归一化算法

  1. 算第 5 和第 95 百分位（不是最小最大值！）：
    p_05 = 第 5 百分位(p_raw)
    p_95 = 第 95 百分位(p_raw)
  2. 截尾（把极端值压回 p_05 / p_95）：
    p_clip(v) = clamp(p_raw(v), p_05, p_95)
  3. 线性映射到 [0, 1]：
    p_norm(v) = (p_clip(v) − p_05) / (p_95 − p_05 + ε)
    ε 是小量防除零（如 1e-9）。
为什么用第 5/95 百分位，不用最小/最大值？
  • 最小/最大值受极端值主导。一个 outlier 体素（如奇异性附近）的 p_ik 可能是 10000，会把整个分布的"100% 位置"拉到 10000，结果中位的体素归一化后只有 0.001，归一化等于没做。
  • 第 5/95 百分位更稳健。把最高 5% 和最低 5% 都视为"极端值"压平，中间 90% 的体素映射到完整的 [0, 1] 范围。

归一化的输出

除了把 4 个 p_*_norm 用于边权，还要在诊断文件 diagnostic.json 里同时记录 raw 和 norm 的分布：

"penalty_stats": {
  "p_clear_raw_p05": 0.0,
  "p_clear_raw_p95": 25.4,
  "p_clear_norm_mean": 0.12,
  "p_orient_raw_p05": 0.1,
  "p_orient_raw_p95": 0.9,
  "p_orient_norm_mean": 0.5,
  ...
}

这样 α/β/γ/δ 的消融实验才有可解释性。

第四节：加权最短路径距离场（核心方程）

本节学完后你应该能：写出最终的边权公式、解释 4 个权重的物理意义、知道为什么要分两遍跑（Pass 1 和 Pass 4）。

最终边权公式

把第三节归一化后的 4 个惩罚项线性组合：

w(u, v) = ||u − v||_mm × [ 1 + α·p_clear_norm(v) + β·p_orient_norm(u,v) + γ·p_curv_norm(v) + δ·p_ik_norm(v) ]
最终边权（v6.2 核心方程）

结构解释：

  • 外层 ||u − v||_mm 是几何长度，毫米单位
  • 方括号内是无量纲膨胀系数，至少为 1（所有惩罚为 0 时退化为纯几何距离）
  • 惩罚越大 → 膨胀系数越大 → 边权越大 → 算法越倾向于绕开

4 个权重的默认值与物理意义

权重默认值物理意义
α1.0凹陷风险与几何距离同等量级
β0.3朝向偏差作为温和倾向，避免过强而退化为水平切片
γ0.1曲率惩罚通常小（第零阶段已抹平大部分）
δ0.5逆运动学项有意义但不压倒几何

为什么要分两遍跑

不能一遍跑完，因为 p_ik 依赖工具姿态，工具姿态又依赖距离场 → 循环依赖。解决方法：分四步（Pass 1 → Pass 2 → Pass 3 → Pass 4）：

  1. 第一遍（Pass 1）：纯几何距离场 D₀
    边权只用 3 项几何惩罚（α, β, γ），没有 δ·p_ik。
    w₁(u,v) = ||u−v|| × [1 + α·p_clear + β·p_orient + γ·p_curv]
    D₀ = Dijkstra(起点=底部, w₁)
  2. 第二步：从 D₀ 估算工具姿态（详见第六节）
    得到每个体素的 tool_z 方向（喷头朝向）。
  3. 第三步：基于工具姿态算 p_ik（详见 2.4 节）
    逐体素算逆运动学边际度。
  4. 第四遍（Pass 4）：完整距离场 D_final
    边权用完整 4 项（含 δ·p_ik）。
    w₂(u,v) = ||u−v|| × [1 + α·p_clear + β·p_orient + γ·p_curv + δ·p_ik]
    D_final = Dijkstra(起点=底部, w₂)

Dijkstra 算法的关键参数

  • 起点：geometric bottom band（z 最小的一层体素，贴平台）
  • 邻接关系：26 邻接（6 面 + 12 棱 + 8 角）
  • 实现：标准 Dijkstra + 优先队列，复杂度 O(N log N)
  • 规模：毛主席 27 万体素，几秒内完成

关键单位审计

D_final_mm 虽然名字带 mm，不是真实物理距离！
D_final 是"加权最短路径累积"，不是欧几里得距离。

举例：同一对相邻体素几何距离 1mm：
  • 在低惩罚区：膨胀系数 1.1 → D_final 增加 1.1
  • 在高惩罚区：膨胀系数 6 → D_final 增加 6
所以"D_final = 1.2mm 等值面"在不同区域物理上对应不同层厚：低惩罚区接近 1.2mm，高惩罚区可能只有 0.2mm（被压扁）。

论文必须明确写："标量场 D 是可制造性加权的最短路径距离，不是欧几里得距离。等值面间距对应实际层厚被局部惩罚调制。"

第五节：有界平滑（消除体素锯齿）

为什么需要

Dijkstra 在 26 邻接体素图上算出来的距离场，本质是分段连续的（沿网格方向量化）。直接对它做等值面提取，表面会有锯齿。

平滑算法

  1. 初始化：D_s = D_final
  2. 迭代 5 轮，每轮：
    D_tmp(v) = 邻域平均(D_s, v 的 26 邻居)
    D_s(v) = clamp(D_tmp(v), D_final(v) − ε, D_final(v) + ε)
    其中 ε = 0.3 × 层厚_mm（默认 0.36mm）
  3. 输出：D_slice_mm = D_s（给等值面提取用）

为什么有"clamp 截断"这一步

关键设计：bounded smoothing（有界平滑）
普通的拉普拉斯平滑会让数值任意扩散，可能让相邻层合并或跨越，破坏层拓扑。

截断到 [D_final − ε, D_final + ε] 区间，保证每个体素的平滑后值不偏离原值太多。

选 ε = 0.3 × 层厚：
  • 太小（如 0.05）：平滑无效
  • 太大（如 1.0）：可能跨层合并
  • 0.3 × 层厚 是经验上"保留拓扑 + 消除锯齿"的最佳折中

三个版本的距离场

名字单位用途
D_final_mmmm原始 Dijkstra 输出，仅诊断用
D_slice_mmmm平滑后，等值面提取用
D_norm无量纲 [0,1]仅可视化，禁止给等值面提取
编译期断言：禁止用 D_norm 切等值面
工程上加单元测试：如果代码里把归一化场传给 Marching Cubes，CMake test 必须 fail。
理由：归一化破坏了物理单位，等值面位置毫无意义。

第六节：工具姿态估计（为逆运动学准备）

本节学完后你应该能：解释 tool_z 用 ∇SDF 而不用 ∇D₀ 的原因。

需要做什么

第三步（Pass 3）算 p_ik 需要知道每个体素处"喷头的姿态是什么"，才能算逆运动学。喷头姿态由 3 个轴决定：

  • tool_z：喷头朝哪
  • tool_x：旋转参考方向
  • tool_y：补全正交系

关键修正：tool_z 用 ∇SDF，不用 ∇D₀

朴素做法：用 D₀ 的梯度方向估 tool_z。

为什么不能用 ∇D₀？
∇D₀ 是加权距离场的梯度，方向受惩罚项主导。

在 p_clear / p_curv 剧烈变化的区域，∇D₀ 主要反映"惩罚梯度"，不是几何法线。

用 ∇D₀ 估的 tool_z 偏离几何法线 → 喷头本体侧壁刮到表面、bead 形状畸变。

正确做法：用 ∇SDF（纯几何法线，与惩罚无关）。

tool_z(v) = −∇SDF(v) / |∇SDF(v)|
喷头朝模型内部（负号）

稳定参考轴的构造

tool_x 应该沿"打印方向"，但路径还没生成！怎么办？用一个稳定参考轴：

  1. 选参考向量：
    ref = world_x if |world_x · tool_z| < 0.9 else world_y
    （如果 world_x 和 tool_z 几乎平行就换 world_y，避免接近 0）
  2. 投影到 ⊥tool_z 平面 + 归一化：
    tool_x_ref(v) = 归一化( ref − (ref · tool_z) × tool_z )
  3. 叉积补全：
    tool_y_ref(v) = tool_z × tool_x_ref

偏航角留作 IK 候选枚举的变量

tool_z 锁定，但喷头绕 tool_z 自旋的"偏航角" ψ 是自由的（任意 ψ 都对应"喷头朝向工件内部"）。第二节 2.4 在算 p_ik 时枚举 12 个 ψ 采样，每个 ψ 对应一个完整姿态。

为什么把 ψ 当变量，不在这里定值？
不同的 ψ 对应不同的最优 IK 解 + 不同的关节角余量。
如果在这里就定一个 ψ（如总是 0°），可能选到一个"机器人勉强能摆但很不舒服"的姿态。
枚举 12 个 ψ + 取最优，能找到"该体素附近机器人最舒服的姿态"，p_ik 才能准确反映"易加工度"。

第六节小结

工具姿态估计是第二节 p_ik 计算的必要前置：
  • tool_z 用 ∇SDF（不是 ∇D₀），保证朝向几何法线方向
  • tool_x/tool_y 用稳定参考轴构造（不依赖路径切线）
  • 偏航角 ψ 留作 IK 候选枚举变量（12 个采样取最优）

总结

整个算法的核心是把"难加工"翻译成"边权惩罚"，让最短路径自然绕开。
