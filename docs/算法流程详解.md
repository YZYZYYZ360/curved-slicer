## 一、项目背景与目标

### 1.1 我们在做什么

把一个三维模型（例如毛主席头雕、armadillo 等 STL 文件）切成一层层"弯曲的薄壳"，每一层的形状会**贴合模型的几何特征**，而不是像传统切片那样用平行于 XY 平面的水平刀切。最终输出每一层的网格，下游 MATLAB 工程会把这些层转成 KUKA 机器人的关节运动。

### 1.2 为什么要弯曲层

传统平面切片在打印**有悬垂或细长结构**的模型时：
- 悬垂区域要支撑材料
- 细长结构（armadillo 的腿）层与层之间方向不连续
- 表面阶梯效应（"楼梯纹"）严重

弯曲层切片让每一层"流着"模型的几何走，避免这些问题。

### 1.3 本项目的算法基础

简化版的 **S³-Slicer**（Zhang et al., SIGGRAPH Asia 2022）算法：
1. 在模型内部求解一个标量场 φ（中文叫"势函数"或"高度场"）
2. φ 的等值面（中文：等高面，类似地形图上的等高线但在三维空间）就是切片层
3. 通过 φ 的边界条件（底面 0、顶面 1 或类似设计），让等值面**自然地从底面贴合到顶面**

### 1.4 与硬件的关系

- KUKA 6 轴机械臂，**工件夹具+打印基板装在臂末端**
- 喷头**固定在世界坐标系的上方**
- 机器人移动工件，让模型当前要打印的点贴到喷头下面，且法向朝上

由于完整的 6 轴运动学已经由实验室既有的 MATLAB 工程处理，**本 C++ 项目不做机器人逆解**，只输出每条路径点的位置和方向（XYZABC），交给 MATLAB。

## 二、算法总览

### 2.1 完整流水线（从 STL 到切片）

```
┌──────────────┐
│  STL 文件     │  三角网格几何（毛主席头雕.stl）
└──────┬───────┘
       │ readStl()
       ▼
┌──────────────┐
│ TriangleMesh │  顶点列表 + 三角形列表 + 包围盒
└──────┬───────┘
       │ voxelizeMesh()
       ▼
┌──────────────┐
│  VoxelGrid   │  把模型切成 0.5mm 的小方块；记录哪些方块是"实体"
└──────┬───────┘
       │ buildSDF()  使用 BVH 加速最近距离查询
       ▼
┌──────────────┐
│     SDF      │  有符号距离场：每个方块到模型表面的距离（内部为负）
└──────┬───────┘
       │
       ├──────────────────┬──────────────────┐
       │                  │                  │
       ▼                  ▼                  ▼
   标量路径            向量路径            （后续：碰撞检测等）
 (scalar)         (vector_kuka)
       │                  │
       │  generateBC()    │  generateVectorBC()
       ▼                  ▼
  标量边界条件        向量边界条件
  底面 φ=0           底面 G=+Z（统一）
  顶面 φ=1           顶面 G=局部外法向（各点不同）
       │                  │
       │ solveLaplacian   │ solveLaplacianVector
       ▼                  ▼
  φ 标量场            G 向量场
  (直接得到答案)    (中间产物)
       │                  │
       │                  │ projectToHemisphere
       │                  ▼
       │              G_clamped
       │              （把朝下的向量推回上半球）
       │                  │
       │                  │ chooseBottomAnchor() + solvePoisson
       │                  ▼
       │              φ 标量场
       │              （从 G_clamped 反积分得到）
       │                  │
       └────────┬─────────┘
                │ gauge shift（重锚定到 min=0）
                ▼
            φ 最终标量场
                │
                │ planIsoLevels()
                ▼
        一组等值面取值（iso 数值序列）
                │
                │ extractIsoSurface() 对每个 iso 值
                ▼
            每层的三角网（IsoMesh）
                │
                ├─→ 输出每层 STL 文件 (iso_NNN.stl)
                ├─→ 计算指标 M1（曲率）、M4（连通性）
                └─→ 输出 metrics.json
```

### 2.2 两条算法路径并存的意义

代码中有两条算法路径，靠 `[algorithm] pipeline` 配置切换：

| 路径名 | 描述 | 何时使用 |
|---|---|---|
| `scalar` | 直接解标量 Laplacian，φ 沿底→顶单调增 | Phase 2 基线版本，简单稳定 |
| `vector_kuka` | 先解向量场 G，再 hemisphere 投影，再解 Poisson 反推 φ | Phase 3 升级版本，理论上能让等值面更贴合几何 |

**论文叙事**：scalar 是"简化版 harmonic 切片"，vector_kuka 是"考虑机器人可达性的弯曲层切片"，两者形成内生对照。

### 2.3 核心数学概念（用大白话解释）

**Laplacian 方程（拉普拉斯方程）**：`∇²φ = 0`
- 物理意义：求一个"最平滑"的场。比如把模型放在热水里，给底面加热到 0 度、顶面加热到 1 度，模型内部的温度分布稳定后就是 φ。
- 用在这里：让 φ 从底面 0 平滑过渡到顶面 1，等值面自然就贴合模型。

**Poisson 方程（泊松方程）**：`∇²φ = ∇·G`
- 物理意义：给定一个"流场" G，求一个势函数 φ，使得 φ 的梯度尽可能贴近 G。
- 用在这里：先单独设计 G（比如让 G 在底面是+Z 方向，在顶面是表面外法向），然后让 φ 来"积分"这个 G。这给我们更多设计自由度。

**等值面（iso-surface）**：
- φ 等于某个常数 c 的所有点构成的曲面，叫 φ=c 的等值面
- 比如取 c=0, 0.1, 0.2, ..., 1.0 共 11 个 iso 值，就得到 11 层
- 提取等值面的算法叫 **Marching Cubes**（中文：移动立方体），下面会详细讲

**Hemisphere clamp（半球投影）**：
- 简单说：把所有"朝下"的向量"扳"回"朝上"
- 物理意义：打印时材料受重力，喷头必须从上方挤出，所以局部打印方向不能朝下

## 三、核心数据结构

### 3.1 Vec3 — 三维向量

定义在 `src/core/types.h`。一个 (x, y, z) 三元组，单位是毫米（mm）。所有空间坐标、方向向量、表面法向都用它。

### 3.2 AABB — 轴对齐包围盒

定义在 `src/core/types.h`。两个 Vec3：min 和 max。整个模型的最小盒子。`size()` 返回 max-min。

### 3.3 Tri — 三角形索引

`{v0, v1, v2}` 三个顶点编号。单独存顶点列表 + 三角形列表是节省内存的标准做法（一个顶点常被多个三角形共用）。

### 3.4 TriangleMesh — STL 读出来的网格

定义在 `src/io/stl_reader.h`。
- `triangles[]`：三角形列表，每个含 3 顶点 + 法向 + 属性
- `bbox`：包围盒
- `format`：ASCII 或 Binary
- `source_path`：来源文件路径（带中文路径支持）

### 3.5 VoxelGrid — 体素网格

定义在 `src/geometry/voxel_grid.h`。把空间切成边长 = `spacing_mm`（默认 0.5mm）的小方块（叫"体素"，英文 voxel = volumetric pixel = 体积像素）。
- `nx, ny, nz`：三个方向各有多少格
- 每个体素有一个状态：是否在模型实体内
- 用 `unordered_set<size_t>` 稀疏存储（只存在实体内的体素），节省大模型内存

**关键参数**：
- `spacing_mm` = 0.5（毫米）：精度。越小越精细但耗时按立方增长
- `padding_mm` = 0：体素网格相对模型 bbox 的额外扩展（当前用 0）

### 3.6 SDF — 有符号距离场

定义在 `src/geometry/sdf.h`。每个体素中心到模型表面的最短距离：
- 实体内部：负值
- 表面附近：接近 0
- 实体外部：正值

**作用**：
1. 判断"哪些体素接近表面"（用于生成边界条件 BC）
2. 通过 SDF 的梯度（变化最快的方向）求出局部表面法向，作为顶面 BC 的方向

**实现**：用 BVH（包围盒层次树）加速从体素到三角形的最近距离查询。

### 3.7 ScalarField — 标量场

定义在 `src/field/poisson.h`。三维网格上每个点的标量值，存在 `values[]` 数组里。Laplacian 标量解 φ、Poisson 解 φ 都用这个类型。

### 3.8 VectorField — 向量场

定义在 `src/field/laplacian.h`。每个点是一个 Vec3。向量 Laplacian 解 G、KUKA 投影后的 G_clamped 都用这个类型。

### 3.9 LaplacianBC / LaplacianVectorBC — 边界条件

```
LaplacianBC（标量）：    fixed_indices[i] 处 φ = fixed_values[i]（数）
LaplacianVectorBC（向量）：fixed_indices[i] 处 G = fixed_vectors[i]（三维向量）
```

简单说就是"在哪些体素强制 φ 或 G 等于多少"。其他没指定的体素自由演化。

### 3.10 IsoMesh — 一层等值面

定义在 `src/surface/iso_surface.h`。Marching Cubes 抽出来的某一层的三角网格。
- `vertices[]`：顶点
- `triangles[]`：三角形索引
- `iso_value`：对应的 φ 值
- `layer_id`：层编号

## 四、各模块详解（按数据流顺序）

### 4.1 STL 读取（src/io/stl_reader）

```
readStl(path) -> TriangleMesh
```

**输入**：STL 文件路径（支持中文）。
**输出**：TriangleMesh，含三角形列表 + 包围盒。
**含义**：把磁盘上的 STL 二进制/ASCII 文件解析成内存里的网格数据。

**关键点**：
- ASCII 与 Binary 自动识别
- 中文路径用 `std::filesystem::u8path` 转换
- 大文件（mao 38MB）流式读取，不一次性加载

**参数**：无可调参数，纯解析。

---

### 4.2 体素化（src/geometry/voxel_grid）

```
voxelizeMesh(mesh, params) -> VoxelGrid
```

**输入**：
- `mesh`：三角网格
- `params.spacing_mm`：体素边长，默认 0.5mm

**输出**：VoxelGrid，标记了哪些体素在模型实体内。

**算法**：
1. 计算包围盒 + padding
2. 按 spacing 划分网格
3. 对每个体素中心做"射线-三角形相交计数"判断是否在实体内（射线穿过实体边界次数为奇数则在内部）
4. 用 (y, z) 平面分桶加速

**参数作用**：
- `spacing_mm` 越小 → 体素越多 → 后续 Laplacian / Poisson 矩阵越大 → 越慢但精度越高
- 0.5mm 是当前实验默认值；调到 1.0mm 矩阵规模降为 1/8，求解快 8-20 倍

---

### 4.3 距离场计算（src/geometry/sdf）

```
buildSDF(mesh, params) -> SDF
```

**输入**：三角网格。
**输出**：SDF 结构，每个体素一个浮点距离值。

**算法**：
1. 构建 BVH（包围盒层次树，加速空间最近查询）
2. 对每个体素中心，用 BVH 找最近三角形
3. 算出最短距离 + 用三角形法向判断符号（内部为负、外部为正）

**关键点**：
- BVH 的目的：把"体素到所有三角形的距离查询"从 O(N×T)（N 体素 × T 三角形）降到 O(N×log T)
- mao 模型 1.3M 体素 × 800K 三角形，没有 BVH 直接卡死

**参数作用**：无直接可调参数，但受 voxel `spacing_mm` 影响（决定 SDF 分辨率）。

---

### 4.4 边界条件生成

#### 4.4.1 标量版本（generateBC，scalar 路径）

```
generateBC(grid, sdf, params) -> LaplacianBC
```

**输入**：
- `grid`：体素网格
- `sdf`：距离场
- `params`：BC 参数（见下）

**输出**：LaplacianBC，含底面体素列表 + 顶面体素列表，分别钉 φ=0 和 φ=1。

**算法**（每个 occupied 体素）：
1. 检查是否在 narrow band（窄带）：`|SDF(voxel)| < bottom_sdf_band * spacing` —— 即距离表面小于一个体素左右，视为"在表面附近"。这是为了排除模型内部深处的体素。
2. 计算局部表面法向：用 SDF 梯度（中心差分），归一化
3. 计算法向与"打印方向"（默认 +Z）的内积 alignment：
   - alignment < `bottom_dot_threshold`（默认 -0.5）→ 法向朝下，是底面体素 → 设 φ=0
   - alignment > `-bottom_dot_threshold`（即 > 0.5）→ 法向朝上，是顶面体素 → 设 φ=1
   - 中间区（侧面）→ 不钉，自由 Neumann 边界

**参数详解**：
- `print_direction`：[0,0,1]，打印方向。改这个会改变"什么算底/顶"
- `bottom_dot_threshold`：-0.5，底面识别阈值。绝对值越大越严，符合条件的体素越少
- `bottom_sdf_band`：1.0，narrow band 宽度（以 spacing 为单位）。值大则更多内部体素被判为"接近表面"，BC 体素更多

#### 4.4.2 向量版本（generateVectorBC，vector_kuka 路径）

```
generateVectorBC(grid, sdf, params) -> LaplacianVectorBC
```

**核心区别**：
- 底面体素：G = +print_direction（**所有底面体素同向**，因为打印基板是平的）
- 顶面体素：G = **该体素处的局部外法向**（**每个顶面体素方向不同**）

**为什么顶面要用局部法向**：
- 如果顶面也用统一 G=+Z，向量 Laplacian 退化为标量场 ×3，最后 Poisson 解 φ 又退化成标量 Laplacian——白绕一圈
- 顶面 G 各点不同，向量 Laplacian 必须真正各方向独立求解，结果是"非平凡"的弯曲场

---

### 4.5 Laplacian 求解

#### 4.5.1 标量版本（solveLaplacian）

```
solveLaplacian(grid, bc, params) -> ScalarField
```

**数学**：求 φ 满足 `∇²φ = 0`（拉普拉斯方程）+ Dirichlet BC（fixed 体素处 φ 取定值）+ Neumann BC（自由边界处 ∂φ/∂n=0，即"边界外没有梯度流出"）。

**离散化**：在每个体素 (x,y,z) 处，
```
6·φ(x,y,z) - φ(x-1,y,z) - φ(x+1,y,z) - φ(x,y-1,z) - φ(x,y+1,z) - φ(x,y,z-1) - φ(x,y,z+1) = 0
```
（只对 occupied 邻居计数；不在 occupied 邻居改成 0）

**求解器**：Eigen 的 ConjugateGradient（共轭梯度法），是大型稀疏对称正定线性方程组的标准迭代方法。

**参数**：
- `max_iterations` = 2000：求解器最多迭代次数
- `tolerance` = 1e-6：相对残差阈值（残差 = ||A·φ - b||/||b||，越小越精确）

#### 4.5.2 向量版本（solveLaplacianVector）

```
solveLaplacianVector(grid, bc, params) -> VectorField
```

**关键技巧**：三个分量 G_x, G_y, G_z 共用**同一个矩阵 A**（结构相同），只是右端项 b 不同。Eigen 的 `compute(matrix)` 一次分解，然后 `solve(b_x), solve(b_y), solve(b_z)` 三次。

**复杂度**：约是标量版本的 3 倍。

---

### 4.6 KUKA Hemisphere 投影（projectToHemisphere）

```
projectToHemisphere(grid, G, params) -> VectorField
```

**目的**：把 G 场中"朝下"的向量"扳"回"上半球"，保证物理可印性（重力下打印方向不能朝下）。

**算法**（每个 occupied 体素）：
1. 取该体素的 G 向量，归一化
2. 计算 G 与 workpiece_up（默认 [0,0,1]）的内积 dot
3. 如果 dot < min_dot_threshold（默认 0.05，即 G 与 +Z 偏离超过约 87°）：
   - 把 G 沿 workpiece_up 方向"推"，使 dot 达到 min_dot_threshold
   - 重新归一化
4. 否则保留原 G

**参数**：
- `workpiece_up`：[0,0,1]，工件本地"向上"方向（与喷头反向）
- `min_dot_threshold`：0.05，最低可接受的与 +Z 的内积。设为 0.05 表示"偏离 +Z 不能超过 87°"——给侧向打印留一点空间

---

### 4.7 Poisson 求解（solvePoisson，仅 vector_kuka）

```
solvePoisson(grid, G, params) -> ScalarField
```

**数学**：求 φ 满足 `∇²φ = ∇·G`（泊松方程）+ 一个 anchor 体素钉 φ=0（消除 gauge 自由度，否则方程有无穷多解）+ 自由 Neumann 边界。

**直观理解**：找一个标量场 φ，让它的梯度 ∇φ 尽可能等于 G。如果 G 本身就"无旋"（curl-free），那 ∇φ 完全等于 G；否则取最佳近似。

**离散化**（每个体素）：
- 左侧：标量 Laplacian（同 4.5.1）
- 右侧：散度 ∇·G ≈ 沿 6 个方向的有限差分

**求解器**：
- `use_precondition = true`（默认）：用 Eigen 的 IncompleteCholesky 预条件 + ConjugateGradient（不完全 Cholesky 预条件共轭梯度法）。这是处理大型稀疏 Poisson 问题的标准选择。
- `use_precondition = false`：纯 CG，对小问题足够。

**参数**：
- `max_iterations` = 500：最多迭代次数
- `tolerance` = 1e-6：残差阈值
- `anchor_voxel`：手动指定 gauge anchor。在 pipeline 里用 `chooseBottomAnchor` 自动选"最朝下的底面体素"作为 anchor（保证 φ 从底面 0 开始）
- `log_iterations`：是否每 50 次迭代打印 error
- `progress_label`：日志前缀（一般是模型名）

**性能瓶颈**：
- bunny 170K 体素：~5s
- mao 568K 体素：**不收敛**（500 次迭代跑满），怀疑是规模问题；mao_0.7x（195K 体素）正在测

### 4.8 Gauge 重锚定（gaugeShiftPhi）

```
gaugeShiftPhi(phi, grid, sdf, boundary) -> phi 就地修改 + 诊断信息
```

**为什么需要**：Poisson 方程在 Neumann 边界下解唯一性是"模 1 个常数"——所有体素 φ 同时加任何常数仍是解。anchor 选不好会导致最终 φ 出现负值（违反"底面 0 顶面正"的约定）。

**算法**：
1. 找全场 φ_min 和 φ_max，记录对应体素索引和世界坐标
2. **闸门 1**：进度（max 投影 - min 投影）应至少 ≥ 半个 bbox 投影长度
3. **闸门 2**：phi_range（max - min）应在 bbox 投影 0.3 ~ 3 倍内
4. **闸门 3**：phi_min 不应低于 phi_range 的 -10%（即负值不超过 range 的 10%）
5. 通过闸门后：所有 φ 减去 φ_min，使 min(φ) = 0

**意义**：让 φ 范围统一为 [0, max]，与 scalar 路径的 [0, 1] 语义对齐，便于下游 iso 抽取。

**诊断输出**（写到 metrics.json）：
- phi_min_pre_shift、phi_max_pre_shift（shift 前）
- min_voxel、max_voxel、min_point、max_point
- min_alignment、max_alignment（仅诊断，不参与放行）

### 4.9 等值面规划与提取

#### 4.9.1 planIsoLevels — 决定取哪些 iso 值

```
planIsoLevels(phi, params) -> std::vector<double>  iso 值列表
```

**输入**：φ 场、IsoExtractParams（含 layer_thickness_mm 等）。
**输出**：一组 iso 值，例如 [0.05, 0.10, 0.15, ..., 0.95]。

**算法**：
- `iso_spacing = "uniform"`（默认）：在 [phi_min + phi_start_offset, phi_max] 区间均匀采样
- 总层数 ≈ phi_range / layer_thickness_mm
- max_layers 是上限（防止参数错误炸出几千层）

**参数**：
- `layer_thickness_mm` = 0.8：相邻 iso 值的间距。在 scalar 路径下是归一化值（0.8/bbox_z），在 vector_kuka 路径下是绝对 mm 值
- `iso_spacing`：目前只支持 "uniform"（均匀）；未来可加 "volume_equal"（按体积均分）
- `phi_start_offset` = 0.0：跳过最底面附近某个 φ 范围（避免抽取底面薄壳）

#### 4.9.2 extractIsoSurface — Marching Cubes 提取一层

```
extractIsoSurface(phi, iso_value, layer_id) -> IsoMesh
```

**Marching Cubes 算法**（中文：移动立方体算法）：
- 把空间划成立方体网格
- 对每个立方体，看 8 个顶点的 φ 值是否大于/小于 iso_value
- 256 种顶点组合 → 查表得到该立方体内的三角形片段（用 mc_lookup_table.h 中的查找表）
- 把所有片段拼起来 = 整个 iso 值的等值面

**参数**：
- iso_value：要提取的 φ 值
- layer_id：层编号（从 0 开始，写到 IsoMesh 里）

**质量**：tetra-decomposition（四面体分解）已切换为表驱动 MC（Phase 2 末期升级），网格更干净。

---

### 4.10 度量指标计算

#### 4.10.1 M1 — 平均曲率最大值

```
maxAbsMeanCurvature(iso_mesh) -> double
```

**意义**：层网格的最大曲率。曲率越大说明层"弯得越急"，物理上对喷头加速度要求越高。论文里用 M1 的下降证明算法生成的层更平滑。

#### 4.10.2 M2 — Hemisphere 违反率

```
hemisphereViolationRatio(grid, G_clamped, params) -> double
```

**意义**：clamp 后还有多少比例的 G 向量 dot < min_dot_threshold。理论上应该是 0%（clamp 已经处理过）。> 0% 说明 clamp 实现有 bug。Phase 3 三模型实测都是 0%。

#### 4.10.3 M4 — 连通性

**两个数值**：
- **per-model connected_components**：把所有层的等值面顶点合并成一个三角网，看连通分量数
  - = 1：模型完整作为一个壳
  - > 1：层之间没共享顶点，说明算法有断点
  - 当前阈值（v4 §6 修订）：最大分量顶点占比 > 99%（允许极小碎片）
- **max(per-layer cc)**：单层最复杂时分多少片
  - armadillo 多腿：scalar 72 片、vector_kuka 36 片（下降 50% 是算法贡献）
  - bunny 圆润：scalar 29 片、vector_kuka 39 片（**反向上升**——算法在凸光滑模型上有副作用，这是 v4 §6.6 修订过的口径，不再要求统一下降）

## 九、调优速查

### 9.1 我想加速

- 调粗体素：`spacing_mm` 0.5 → 1.0（mao 总耗时从 ~10 分钟降到 ~1.5 分钟）
- 关掉 debug：`debug_dump_intermediates = false`
- 求解器降精度：`tolerance` 1e-6 → 1e-4（影响小，速度提升有限）

### 9.2 我想精度更高

- 调细体素：`spacing_mm` 0.5 → 0.25（耗时增 8 倍，内存增 8 倍）
- 求解器加精度：`tolerance` 1e-6 → 1e-9
- 增加 max_iterations：500 → 2000（如果不收敛）

### 9.3 我想等值面更多层

- 减小 `layer_thickness_mm`：0.8 → 0.4
- 增大 `max_layers` 上限

### 9.4 vector_kuka 解不出来

- 切回 `pipeline = "scalar"` 作为基线
- 关掉 `use_precondition`（小模型有时反而更稳）
- 缩小模型（mao 问题正在测）

### 9.5 等值面有断片（per-layer cc 大）

- 这是几何特征，不是 bug
- 可调 `bottom_dot_threshold` 让顶面/底面识别更宽（但效果有限）
- 可在 v4 §7（待写）实现 G 平滑预处理
