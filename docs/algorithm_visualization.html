约束波前 + PDE 平滑算法可视化

为 KUKA KR4 R600 六轴 FDM 曲面打印设计，同时满足 support-free / 曲率不干涉 / 收敛三大约束

Part 1：四条根本约束

任何"层 N+1 可打印于层 N 之上"必须同时满足下面 4 条。少一条都会出问题。

🧱

C1 ASN 结构

新体素 v 必须至少有 1 个 ASN（18 邻居：6 面 + 12 棱）在已打印集合里。这样新材料能黏住前层。
🦾

C2 IK 可达

在该位姿 (X,Y,Z + 朝向)，IK 必须解得出 6 关节角，且都在 qlim 内，远离奇异区，在工作空间内。
⚠️

C3 喷头不撞

喷头是圆柱体（半径 r，高 h），从 TCP 沿 -tool_z 方向延伸。圆柱不能撞已打印部分。
🔄

C4 曲率不干涉

曲面每点曲率 |H| < 1/r_nozzle。否则喷头塞不进凹陷，物理上不可打印。

Phase A：预处理

  • A1：把 STL 切成立方体素（默认 spacing=0.5mm）
  • A2：算每个 voxel 的 SDF（到表面距离）
  • A3：算每个 voxel 表面的曲率 H(v)（SDF Hessian 特征值估）
  • A4：标"先天不可救"体素：|H(v)| > 1/r_nozzle 直接打 SHADOW
  • A5：解 G 场（每 voxel 的工件外法向）—— 仅用于后续工具姿态，不用于推进
输出：每 voxel 有 SDF + 曲率 + G 方向；SHADOW 体素已标

Phase B：约束波前推进（算法核心）

从平台开始，一层一层往外推。每个候选 voxel 必须同时通过 C1+C2+C3+C4 才能加入下一层。

L_1 = 平台贴附体素 (geometric_z 内 bottom band)
processed = L_1
layer_idx = 1

while unprocessed 非空:
    candidates = {}
    for v in L_layer_idx:
        for v_a in ASN(v):              # 18 个邻居方向
            if v_a 已处理: continue
            if not C1(v_a, processed): continue   # 至少 1 个 ASN 已处理
            if not C2(v_a, G(v_a)): continue       # IK 可达
            if not C3(v_a, processed): continue    # 喷头不撞
            if not C4(v_a): continue              # 曲率 OK
            candidates.add(v_a)

    if candidates 空:
        触发 Phase B.5 救援
    else:
        # 精选：按 G 投影距离 + 单连通分量
        L_next = select_thin_connected(candidates)
        processed ∪= L_next
        layer_idx += 1
输出：每个 voxel 都有整数层号 L(v) ∈ {1, ..., K}，构造保证 C1~C4

Phase B.5：救援机制

当 candidates 空，但还有未处理 voxel 时，按梯度放宽约束：

  1. Step 1：放宽 C4 阈值 1.2× —— 喷头能塞 r/1.2 半径的凹陷
  2. Step 2：放宽 C3 margin 0.8× —— 安全距离从 5mm 减到 4mm
  3. Step 3：仍空 → 当前 unprocessed voxel 标记 SHADOW，跳到下层继续
  4. Step 4：累计 SHADOW 率 > 30% → 算法失败 abort
收敛性证明：每次循环要么推进 ≥1 voxel，要么消耗 ≥1 voxel 为 SHADOW。 unprocessed 集合单调减小 → 有限步终止

Phase C：PDE 后平滑

Phase B 输出整数层 L(v)，直接切等值面会有 voxel 锯齿。用 Poisson 后平滑：

φ_target(v) = L(v) / max(L) ∈ [0, 1]

minimize ∫(|∇φ|² + λ·|φ - φ_target|²) dV
subject to φ(bottom)=0, φ(top)=1

自适应 λ：每层 λ 由 ASN 满足率决定 —— 结构紧绷的层用大 λ（严格跟 L），结构松的用小 λ（PDE 主导平滑）。

输出：光滑 φ 场，iso-surfaces 不再有 voxel 锯齿，但拓扑（层数 + 连通性）由 Phase B 保证

Phase D：等值面提取 + 验证

  • D1：MC 提取等值面 at uniform φ spacing (0.1, 0.2, ..., 0.9)
  • D2：§20 连通性过滤（每层最大连通分量）
  • D3：§21 ASN per-vertex 二次验证（应近 100% 通过）
  • D4：任一层失败率 > 5% → 算法 abort

Phase E：路径生成 + 6 轴轨迹

这部分沿用 v4 §13/§11/§12/§14：

  • E1：测地等值线提取路径（libigl exact_geodesic + isolines）
  • E2：笛卡尔位姿构造 + KR4 R600 解析 IK
  • E3：可达性双层过滤（B 体素级 + C 路径点级）
  • E4：5 次多项式关节角轨迹平滑（4ms 周期对齐 RSI）
最终输出：trajectory.csv（每帧 6 关节角 + wire_on + PLC 信号）
