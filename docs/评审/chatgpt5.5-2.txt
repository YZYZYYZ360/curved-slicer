## 结论先行

**v5 仍然不适合作为 7 周内“bunny + armadillo + mao + KR4 + RSI + 实机”的完整毕业主线。**
它比 v4 更诚实，但又引入了一个新根本问题：

> **你把“制造可行性”错误地降维成了“拓扑复杂度路由问题”。**

Reeb graph、genus、bifurcation degree 只能描述几何/拓扑结构的一部分，不能可靠判断喷头 clearance、机器人可达性、IK 连续性、同层碰撞、路径连续性和材料粘结。你现在的 Stage 2 用 `g` 和 `b` 决定走 3a 还是 3b，这个判据太弱；一个 `g=0, b=0` 的深杯形凹腔就能让 Stage 3a 失败，一个 `g=1` 但几何很简单的 torus 又会被过度分区。你在 v5 中明确把 routing 规则写成 `g=0,b≤1 → 3a；g=0,b>1 → 3a + variable nozzle；g>0 或 b 很高 → 3b`，这正是会被反例击穿的地方。

**7 周内最现实的目标**不是完整 v5，而是：

> **做一个稳定曲面切片 pipeline：geometry conditioning + scalar-field / weighted-distance curved slicing + 后验 IK / collision heatmap + 1 个模型实机低速演示。mao 只做 stress test，不承诺完整打印。**

如果坚持 v5 全部内容，我的悲观估计是 **12–20 周**，而且还不保证 mao 实机成功。

# P0-1：Stage 2 路由决策不鲁棒

**判定：不成立。**

你的 `g, b, critical points` 只能作为诊断指标，不能作为主路由决策。Reeb graph 很有用，但它不是制造可行性的充分条件。

## 具体缺陷

第一，**`g=0, b≤1` 不代表可以 single-pass curved slicing。**
反例：一个 smooth deep cup、眼窝、鼻孔、耳道、内凹 U 形沟槽，拓扑上都是 genus 0，bifurcation 也可以很低，但喷头半径 `r_n=10mm` 的圆柱可能完全塞不进去。你的 Stage 2 会把它送进 Stage 3a，但真正失败点是 clearance，不是 topology。

第二，**`g>0` 不必然需要分区。**
一个尺寸足够大、开口足够宽的 torus 或环形支架，可能可以用单一 scalar field 生成可接受曲面层。你现在的规则会把它强行送进 3b，增加接缝、顺序规划和 bonding 风险。

第三，**Reeb graph 依赖标量函数。**
你写的是沿 build direction 的高度函数做 Morse 分析，但高度函数的 critical points 会随模型姿态改变。mao 头雕旋转 20°，critical point 数量、branch 结构和 saddle 位置都可能变化。你不能把 `b` 当成模型固有复杂度。

第四，**噪声和细节会污染 Reeb graph。**
mao 头发褶皱有 `<1mm` 细节，如果不做 persistence simplification，Reeb graph 会产生大量伪 critical points；如果 smoothing 太强，拓扑图稳定了，但头雕识别度可能丢失。

第五，**Jayakody 2024 已经把 Reeb graph / Morse 用在 collision-prone region 识别和 nozzle orientation optimization 上。** 你的“按 Reeb graph 路由 single-pass vs partition”的 claim 很容易被认为是 Jayakody 2024 + Lau 2023 partition planning 的工程组合，而不是新理论。Jayakody 2024 明确提出 topology-aware framework，用 Reeb graph / Morse 思想识别 global collision-inducing features，并优化 nozzle orientation vector field 以实现 collision-free、support-free curved layer MAAM；Lau 2023 也已经做 partition-based print sequence planning + adaptive slicing，通过迭代分区建立 collision-free print sequence。([科学直通车][1])

## 修改建议

Stage 2 不要输出硬路由：

```text
if g=0,b≤1 -> 3a
else -> 3b
```

改成打分制：

```text
score_single = w1 * clearance_score
             + w2 * ik_continuity_score
             + w3 * scalar_field_quality
             + w4 * layer_component_penalty
             + w5 * reeb_complexity_score

if score_single ≥ threshold:
    use single-pass
else:
    use partition
```

其中最重要的不是 `g`，而是：

```text
minimum nozzle clearance
IK success rate
IK branch continuity
expected collision-prone region area
field monotonicity violation
layer fragmentation ratio
```

Reeb graph 只做辅助，不做唯一判据。

# P0-3：Stage 3a 本身还有数学漏洞

**判定：当前描述不完整，甚至有错误。**

你写 Stage 3a 是 heat geodesic distance `d(v)`，`H=∇d`，RBF 权重调制，然后解 Poisson `∇²φ = ∇·H_weighted`，并声称 `φ` monotonic along build direction。这里有三个硬伤。

## 具体缺陷

第一，**surface geodesic field 不是 volume slicing field。**
Heat geodesic distance 通常在表面 mesh 上定义。你要切的是实体体积，需要 `φ(x)` 在 volume / voxel / tetrahedral domain 上有定义。否则 Marching Cubes 提取 volume iso-surface 没有稳定输入。你必须说明：

```text
是在 surface mesh 上切 shell？
还是在 tetrahedral volume 上切 solid？
还是在 voxel grid 上解 scalar field？
```

这三者完全不同。

第二，**RBF scalar weight 只改 magnitude，不改 direction。**
你写：

```text
H_weighted(v) = H(v) · Σω_i φ(||v-c_i||)
```

这是标量乘法。它不能真正优化 nozzle vector 朝 outward，也不能显著改变 collision-prone region 的方向场结构。Jayakody 2023 的 RBF field 是用来修改 fabrication sequence field，目标是降低 collision-inducing layer features 并做 adaptive layer thickness；不是简单乘一个 scalar weight 就能等价复现。([MDPI][3])

第三，**Poisson 不保证 monotonicity。**
`∇²φ = ∇·H` 得到的是最小二乘意义上的梯度投影，不保证 `φ` 沿 build direction 或支撑方向严格单调。除非你加 inequality constraints，例如：

```text
φ(v_j) - φ(v_i) ≥ ε    for directed support edges i -> j
```

否则 local extrema、folding、layer merging 仍然可能出现。你在 v4 已经接受了“PDE 后平滑不能 claim 拓扑等价”的问题，v5 这里不能换成“monotonic increasing”继续强 claim。

## 修改建议

毕业版不要复现完整 Jayakody 2024。改成更稳的：

```text
voxel/tet domain 上的 weighted shortest-distance scalar field
```

即：

```text
D(v) = shortest weighted distance from bottom/source region
w(u,v) = length(u,v) * [1 + α orientation_penalty + β clearance_penalty]
```

然后：

```text
iso-surfaces of D -> curved layers
```

这个比 Poisson/RBF/orientation optimization 稳得多，也更适合 7 周。

# P1-7：IK branch DP 具体化

**判定：你的 O(8²N) 思路成立，但还不够。**

如果只有 8 个 IK branch，Viterbi / DP 是对的。状态：

```text
state(i, b) = 第 i 个路径点选择第 b 个 IK 解
```

转移：

```text
cost(i-1,a -> i,b) =
    wq * ||wrap(q_i^b - q_{i-1}^a)||²
  + wv * velocity_penalty
  + ws * singularity_penalty
  + wc * collision_penalty
```

硬约束：

```text
q_i^b inside joint limits
σ_min(J(q_i^b)) ≥ ε
|wrap(q_i^b - q_{i-1}^a)| ≤ qdot_max * Δt
collision_free(q_{i-1}^a -> q_i^b)
```

伪代码：

```python
S[i] = all_valid_IK_solutions(p[i], R[i])  # up to 8

dp[0,b] = start_cost(q[0,b])

for i in range(1, N):
    for b in S[i]:
        dp[i,b] = inf
        for a in S[i-1]:
            if violates_velocity(q[i,b], q[i-1,a]): continue
            if violates_acceleration_if_available(i,a,b): continue
            if swept_collision(q[i-1,a], q[i,b]): continue

            c = dp[i-1,a] + transition_cost(a,b)
            if c < dp[i,b]:
                dp[i,b] = c
                parent[i,b] = a

best = argmin_b dp[N-1,b]
backtrack(best)
```

但有四个补充：

1. **闭合曲线要 cyclic DP。**
   曲面层路径常是闭合 contour。你要保证 `q_N` 能回到 `q_0`，否则一圈结束出现腕部跳变。做法是枚举起始 branch，强制终点 branch 接近起点。

2. **tool yaw 也要进状态。**
   如果喷头绕切向/法向有自由角，不是 8 个 branch，而是：

   ```text
   state = IK_branch × yaw_sample
   ```

   例如 yaw 采 8 个角，状态就是 64 个，复杂度变成 `O(64²N)`，仍可接受，但要剪枝。

3. **4ms 不应固定用于所有路径点。**
   你应该先生成几何路径点，再按 joint velocity / acceleration 重新 time-parameterize。否则路径采样太密时速度很慢，太稀时违反加速度。

4. **quintic smoothing 后要重新验证。**
   DP 通过的是离散点，五次多项式插值后中间姿态可能碰撞或奇异。Stage 5 必须再做 dense validation。

# P2-10：如果不用 Jayakody 2024，我会怎么 redesign

我会完全砍掉 v5 的 routing + Jayakody reproduction，做一个保毕业的 **Clearance-weighted scalar-field slicer**。

## 新方案

```text
1. Mesh conditioning：只做 decimation / hole fix / small feature removal
2. Voxel or tetrahedral volume domain
3. Compute clearance field C(x)
4. Compute weighted distance field D(x) from base
5. Extract iso-surfaces D(x)=k*h
6. Generate contour paths on each layer
7. IK DP + collision post-check
8. Report failure heatmaps
```

边权：

```text
w(u,v) =
    ||u-v|| *
    [1
     + α * orientation_penalty(u,v)
     + β * clearance_penalty(u,v)
     + γ * curvature_penalty(u,v)]
```

其中：

```text
clearance_penalty = max(0, r_n + margin - C(v))²
orientation_penalty = 1 - |dot(normalized(u-v), preferred_growth_direction)|
```

优点：

```text
比 Poisson 稳
比 Reeb routing 简单
能自然绕开低 clearance 区域
可以解释为 shortest manufacturability distance field
更容易 7 周出结果
```

论文 claim：

> “A clearance-weighted scalar-field method for robust curved-layer generation, with robot-specific post-certification.”

这比 “Topology-Adaptive Hybrid Jayakody+Wu+TTK+RSI” 小很多，但更可能毕业。

# v5 的 adversarial inputs

## 反例 1：smooth deep cup

```text
genus = 0
b = 0
surface curvature low
deep cavity opening width < 2*r_n
```

Stage 2 会选 3a，但喷头进不去。Stage 1 curvature smoothing 也不会修，因为曲率不高。失败原因是 clearance，不是 topology。

## 反例 2：mao 头发纹理

```text
大量 <1mm high-curvature grooves
整体 genus = 0
局部语义特征重要
```

Stage 1 若 smoothing 强，mao 失去识别度；若 smoothing 弱，Stage 3b 仍被大量 critical points / collision-prone regions 淹没。

## 反例 3：torus with large clearance

```text
genus = 1
几何简单
喷头 clearance 足够
```

Stage 2 强制送 3b，但 single-pass 可能足够。说明 `g>0 -> partition` 是过度保守。

## 反例 4：two-lobe model with narrow neck

```text
两个球由窄颈连接
g = 0
b 可能很低
```

Stage 3a 可能生成层合并/分裂；Stage 3b 若切在 neck，接口强度很差。

## 反例 5：closed-loop contour IK wrist flip

几何层面完全合理，但某一圈路径绕过机器人 wrist singularity，8 解逐点存在，DP 找不到 cyclic continuous branch。说明 geometric slicing 成功不等于 KR4 trajectory 成功。

# 最终建议：7 周保毕业版本

## 砍掉

```text
砍 Stage 3b 自动 Reeb partition
砍 Jayakody 2024 完整复现
砍 mao 完整实机打印承诺
砍 RSI 4ms 在线规划
砍 “首次 topology-adaptive routing” 强 claim
```

## 保留

```text
保留 geometry conditioning，但加 Hausdorff / volume / normal deviation bound
保留 scalar-field curved slicing
保留 IK DP 后验验证
保留 FCL offline swept collision
保留 bunny 实机或 dry-run
保留 armadillo + mao 可视化和 failure heatmap
```

# 审稿式结论

**v5 不能按当前形式投 SCI Q4 / EI。**
原因不是没有想法，而是 scope 失控：Stage 1 是形状优化，Stage 2 是拓扑分析，Stage 3a 是 Jayakody 复现，Stage 3b 是分区与接缝规划，Stage 4/5 是机器人轨迹与实时控制。每一项都能单独成为一个项目。把它们合成 7 周 pipeline，最大概率是每个模块都半成品。

**可投 EI / SCI Q4 的版本应该收缩成一个工程可跑通的 pipeline：曲面层生成 + 机器人后验验证 + 失败分析。**
新颖性不要押在“首次 topology-adaptive routing”，而押在“KR4-specific practical implementation + clearance-aware scalar field + systematic failure maps”。这不华丽，但更可能毕业。
